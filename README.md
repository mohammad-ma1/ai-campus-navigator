# AI Campus Navigator

A student survival guide to LLMs — a multi-page website built with plain **HTML, CSS and JavaScript** in VS Code and hosted on **GitHub Pages**.

## Pages
- `index.html` — home page and trail map of 9 stations
- `journey.html` — choose your AI study path
- `prompt-battle.html` — weak vs strong prompts
- `mistake-detector.html` — interactive "spot the AI mistake" game
- `privacy-meter.html` — privacy risk levels (filterable)
- `exam-mode.html` — five study modes with prompts
- `ethics.html` — AI ethics traffic light
- `quiz.html` — tool finder personality quiz
- `survival-kit.html` — printable survival kit
- `llms-101.html`, `compare.html`, `capabilities.html`, `choose.html`, `use-cases.html`, `engineering.html` — reference pages

## Files
- `style.css` — shared styles (responsive, Flexbox/Grid)
- `script.js` — shared JavaScript (mobile menu, copy buttons, filter tabs)
