Section 7

Choosing the right tool

No tool is best at everything. Match the tool to the task.

IF YOU NEED

I need to understand a topic

USE

A chatbot / tutor-style LLM

EXAMPLES

ChatGPT, Claude, Gemini

IF YOU NEED

I need real sources & citations

USE

An AI search tool

EXAMPLES

Perplexity

IF YOU NEED

I need coding help

USE

A code-savvy chatbot or in-IDE assistant

EXAMPLES

ChatGPT, Claude, GitHub Copilot, Cursor, Replit

IF YOU NEED

I want to build a working app

USE

An AI app-builder

EXAMPLES

Lovable, Bolt, Replit, v0

IF YOU NEED

I'm in Google Docs / Gmail all day

USE

Google's assistant

EXAMPLES

Gemini

IF YOU NEED

I'm in Word / Excel / Outlook all day

USE

Microsoft's assistant

EXAMPLES

Microsoft Copilot

IF YOU NEED

I'm working with private or personal info

USE

Avoid uploading it. Use anonymized samples or a privacy-focused setup

EXAMPLES

Local Llama / Mistral, or your university's approved tool

IF YOU NEED

I want something free and beginner-friendly

USE

Free tiers of major chatbots

EXAMPLES

ChatGPT free, Claude free, Gemini free
